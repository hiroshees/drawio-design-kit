# 図の新規作成

引数：$ARGUMENTS

## 1. 引数を読み取る

- 最初の語が図の種類。次のどれか（日本語名でもよい）
  - usecase（ユースケース図）、class（クラス図）、sequence（シーケンス図）、activity（アクティビティ図）、state（ステートマシン図）、er（ER図）、screen（画面遷移図）
- 残りが図の内容
- 種類がわからない、または内容が空のときは、作業を始めずに、種類の一覧を示して聞き返す

## 2. 描く前に、要素の一覧を示して確認を取る

- 内容から、図に必要な要素を一覧にする
  - 例：アクターとユースケース、ライフラインとメッセージ、テーブルと列、画面と遷移
- 内容に書かれていないことは推測で埋めず、「不明点」として一覧の最後に挙げる
- 一覧を示したら、ここで止めてユーザーの確認を待つ

## 3. 図を作る

- 確認が取れたら、drawio-diagram スキルの手順とルールに従って作る
- ファイル名の「名前」の部分は、内容を表す英小文字とハイフンで付ける（例：`sequence-cancel.drawio`）。同じ名前のファイルがすでにあれば、上書きせずに別の名前にする

## 4. 報告する

- drawio-diagram スキルの「作成後のセルフチェック」の結果
- 「Export が必要なファイル」の一覧
