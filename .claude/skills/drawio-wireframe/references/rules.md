# ワイヤーフレーム作成ルール

## 1. ファイルとページ

- 置き場所：`outputs/wireframes/drawio/`。1 つの `.drawio` が 1 つの画面
- ファイル名：`wf-<画面ID>-<名前>.drawio`（画面 ID は小文字、名前は英小文字とハイフン）。例：`wf-sc01-login.drawio`
- ページは、PC 版を `pc`、スマホ版を `sp` とする。順番は `pc`、`sp`。片方しか作らない画面は、その 1 ページだけでよい
- 同じ画面の別の状態（メニューを開いた、ダイアログを出した、など）は、版の名前に「-状態名」（英小文字と数字）を付けたページを足す（例：`sp-menu`、`pc-dialog`）
  - 画面枠の大きさは、名前の先頭（`pc` か `sp`）で決まる
  - 順番は `pc`、`pc-状態名`、`sp`、`sp-状態名`。状態のページは、状態名のないページの後に置く
  - 状態のページの注釈は、その状態で増えた部品と、通常の状態との違いだけでよい
- 書き出し：`outputs/wireframes/{svg,png}/<ファイル名>-<ページ名>.svg`（`.png`）。ページごとに別の画像になる
  - ページ名は、英数字・ハイフン・アンダースコアだけ。重複と不正な名前は、書き出しを拒否される

## 2. 画面サイズ

| ページ | 画面枠の大きさ | 画面枠の位置 |
| --- | --- | --- |
| `pc` | 1280×800 | 左上を (0, 0) |
| `sp` | 375×812 | 左上を (0, 0) |

- 画面枠は、角丸なしの四角形（`rounded=0`、塗り白、線 `#666666`）。ページの最初の部品とする
  - 幅は規定どおり（1280 か 375）。高さは規定（800 か 812）以上。内容が収まらないときだけ、高さを伸ばす
  - 高さを伸ばしたときは、規定の高さの位置（`pc` は y=800、`sp` は y=812）に、画面の下端を示す点線を `frame` レイヤーに引く。線の右（枠の外）に、「↑ 1 画面目の下端（812）。これより下はスクロールして見る」と書く（例：`wf-sc08-create.drawio` の `sp`）
  - PC 版も、ブラウザ枠（`containers.browserWindow`）は使わず、同じ四角形にする（アドレスバーの分だけ、1280×800 の領域が読み取りにくくなるため）
- 画面枠の外（上）に、画面 ID と画面名と版を書く（例：「SC-01 ログイン（pc）」）。文字は左寄せ、枠の左端にそろえる
- **375 と 812 は、8 の倍数ではない**（8 の倍数にすると実機の大きさと変わるため、画面枠だけは例外にする）
  - 画面枠の内側の部品は、8 の倍数の座標・大きさに従う
  - 画面枠の上の見出しの幅は、375 ではなく 376 にする（見出しは部品なので、8 の倍数に従う）
  - 画面の幅いっぱいの部品（ヘッダーなど。x=0 で、幅が画面枠と同じ）は、幅だけ 8 の倍数でなくてよい（`sp` のヘッダーは幅 375）

## 3. グリッドと余白

- グリッドは 8px（`gridSize="8"`）。UML 図の 10px とは別
- 部品の座標（x, y）と大きさ（幅, 高さ）は、8 の倍数にする。画面枠は例外
  - 部品の標準の大きさは、`catalog.md` のとおり（高さ 32、40 など）。すべて 8 の倍数
- 画面の端から部品までの余白：`pc` は 32、`sp` は 16
  - 共通のヘッダー（`frame` レイヤー）：`pc` は高さ 80（タイトル y=16・高さ 48、リンクバー y=24・高さ 32）、`sp` は高さ 56（タイトル y=8・高さ 40）。`sp` は、リンクの代わりに右上に「☰」を置く
  - `pc` の一覧・フォームなど幅が要る画面は、内容の幅を 960（x=160）や 640（x=320）にしてよい。ログインのような短い画面は、幅 320 の 1 列
  - `sp` の内容の幅は **344**（左の余白 16、右の余白 15）。左右とも 16 にすると幅が 343 になり、8 の倍数にならないため
  - `pc` の内容は、画面の中央に幅 320 の 1 列（x=480）を基本とする
- 部品どうしの間隔
  - ラベルと入力欄：8
  - 入力欄どうし、ラベルと次のまとまり：24
  - 主なボタンの前、見出しの次のまとまり：32
- 画像の余白（書き出しの `border`）は、UML と同じ 20px。画面内の余白とは別

## 4. レイヤー

画面ごとに、次の 3 つのレイヤーを、下から順に作る。名前は英小文字。

| レイヤー名 | 入れるもの |
| --- | --- |
| `frame` | 画面枠、ヘッダー、フッターなど、画面の共通部分 |
| `parts` | 画面の中身の部品 |
| `notes` | 注釈（番号の丸と補足の文章） |

- 部品は、必ずいずれかのレイヤーに置く（既定のレイヤーには置かない）
- 注釈を隠した状態でも、画面として成り立つ図にする
- XML では、レイヤーは `<mxCell id="…" value="frame" parent="0" />` のように、`parent="0"` で作る。部品の `parent` には、レイヤーの id を指定する

## 5. 注釈の書き方

- 番号の丸：直径 24、赤（`#FF0000`）の線と白抜き、数字は赤。対象の部品の左上（x−16、y−8）に、部品に少し重ねて置く
  - 部品の箱が、見える中身より大きいと、丸が中身から離れる。箱は、見える中身に合わせた大きさにする（例：ページ送りは幅 96）
  - 対象が文字（テキスト）のときは、左上に置くと先頭の文字を隠す。丸は、文字の右に置く（例：`pc` は x=360、`sp` は x=224。文字の長さに合わせて調整する）
- 補足の文章：画面枠の右側（枠から 40 離す）に、番号順に縦に並べる。書式は「番号．対象：内容」（例：「1．メールアドレス：必須。形式チェックあり」）
  - `pc` は x=1320、`sp` は x=416（どちらも 8 の倍数に合わせる）
- 注釈に書くのは、見た目から読み取れないこと（必須、文字数、押したときの遷移先、表示条件）だけ

## 6. 色と文字

- 色は、グレー階調と強調色 1 色（青）に絞る
  - 線 `#666666`、塗り `#FFFFFF` または `#DDDDDD`、文字 `#333333`
  - 強調（主なボタン、選択中）：青 `#008CFF`（Mockups 図形の既定色）
  - 赤は、注釈だけに使う
- 文字は日本語。ダミー文言は、実在しない例を使う（例：「山田 太郎」、`taro@example.com`）。ボタンの名前は、押したときの動作（「ログイン」「申し込む」）にする
- 文字の大きさ：本文・ラベル・入力欄 14、システム名 16、見出し 24、注釈 12
  - テキストは `fontSize`、Mockups 図形の中の文字は `textSize` で指定する（既定は 17 で、大きい）
  - 文字色は `#333333`、入力欄のダミー文言は `#999999`、ボタンの文字は白（`textColor=#FFFFFF`）

## 7. 部品の使い方

- 使える図形は、`catalog.md` の「採用」だけ。ここにない図形は、描画を確認してから `catalog.md` の採用リストに追加する
- 図形の中の文字は、`value` ではなく属性（`mainText` など）で指定する。`value` に書くと、既定の英文字と重なる（詳細は `catalog.md`）
- `mainText` を数字だけ（`mainText=1`）にしない。draw.io の書き出しが失敗する（原因は未確認）。ページ送りのボタンなどは、全角の数字（`mainText=１`）にする。チェックスクリプトが検出する
- 既定の英文字（Main Text、Option 1 など）を、画面に残さない（チェックスクリプトでは確かめられないので、PNG を見て確認する）
- 次の 2 点は、許容している
  - ボタン（`buttons.button`）の角は、図形の既定の丸いまま。入力欄の四角には合わせない
  - パスワード欄（`forms.pwField`）の文字の左の余白が、入力欄より 4px ほど小さい

## 8. チェックスクリプトが確かめる項目

`outputs/wireframes/drawio/` の `.drawio` を保存すると、hook が `.claude/hooks/check_wireframe.py` を実行する。

| 項目 | 内容 |
| --- | --- |
| ファイルの形式 | XML として読める。非圧縮。背景が白（`background="#FFFFFF"`） |
| ファイル名 | `wf-<画面ID>-<名前>.drawio`（英小文字・数字・ハイフン） |
| ページ名 | `pc` か `sp`。状態のページは `sp-menu` のように「-状態名」を付ける。重複しない。順番は `pc`、`pc-状態名`、`sp`、`sp-状態名` |
| 画面枠 | 各ページに、左上が (0, 0)、幅が規定（`pc` は 1280、`sp` は 375）、高さが規定（800、812）以上の四角形がある。規定より高いときは、規定の高さの位置に、`frame` レイヤーの点線がある |
| 8 の倍数 | 画面枠以外の部品の x、y、幅、高さが 8 の倍数（画面の幅いっぱいの部品の幅は除く） |
| レイヤー | `frame`、`parts`、`notes` が、この順にある。部品がどれかに属する |
| 図形名 | `shape=mxgraph.mockup.*` が、`catalog.md` の採用リストにある |
| 文字 | `mainText` が数字だけでない（書き出しが失敗するため） |

機械では確かめにくいもの（余白の適切さ、注釈の内容、既定の英文字の残り、見やすさ）は、セルフチェックで、PNG を見て確認する。
